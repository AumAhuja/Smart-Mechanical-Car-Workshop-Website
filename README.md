🚗 Car Service Website

A modern, fully responsive Car Service Website built using HTML, CSS, and JavaScript.
The project simulates a real-world automobile service platform with service listings, mechanic profiles, gallery preview, and online booking functionality.

🌟 Features

✅ Responsive design (Desktop, Tablet, Mobile)

✅ Service filtering using JavaScript

✅ Mechanic profiles section

✅ Interactive gallery with modal image preview

✅ Booking form with validation

✅ Contact form with submit confirmation

✅ Clean and structured UI design

🛠️ Technologies Used

HTML5

CSS3 (Flexbox + Grid)

JavaScript (DOM Manipulation)
